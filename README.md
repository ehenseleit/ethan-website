# Ethan Henseleit | Personal Website

**[Visit the website](https://ehenseleit.com)** · **[LinkedIn](https://www.linkedin.com/in/ethan-henseleit/)**

This repository contains the source code for my personal website. I'm a software test engineer in the games industry and I built this site to share the games I have worked on and a little about myself.

## Features
- **Interactive cards** — Cards for the games I've worked on that can be flipped to learn more behind the credit.
- **Light and dark themes** — Follows the system preference by default and remembers a manually selected theme.
- **Responsive layout** — Designed for desktop and mobile.
- **Accessibility** — Keyboard-operable cards, visible focus states, and reduced-motion support.
- **Haptic feedback** — Feedback on card interactions on supported devices and browsers.
- **Contact form** — Powered by Formspree.
- **QA-inspired details** — A small debug mode and a few surprises for curious visitors.

## Built With

- HTML
- CSS
- JavaScript (with assistance from ChatGPT)
- [Formspree](https://formspree.io/)
- [Cloudflare Pages](https://pages.cloudflare.com/)

## Project Structure

| File | Purpose |
| --- | --- |
| `index.html` | Main page content and structure |
| `styles.css` | Layout, themes, styling, and responsive behavior |
| `theme.js` | Theme switching and preference persistence |
| `card.js` | Interactive project card behavior |
| `extras.js` | Additional interactions and debug features |
| `assets/` | Images, audio, and résumé files |
